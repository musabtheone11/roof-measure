How to get a key (one time, about 5 minutes)
  1. Go to console.cloud.google.com, create a project, and enable billing. Google includes a monthly free credit that covers typical use.
  2. APIs & Services → Library → enable Maps JavaScript API, Geocoding API, Solar API, and Maps Static API (used for the report photo).
  3. Credentials → Create credentials → API key. Under API restrictions, limit it to those 4 APIs. Leave website restrictions off if you open this file by double-clicking it.
  4. Paste the key above and click Save. It is stored only in this browser.

Pulls Google's 3D roof model for this building: total roof area, footprint, and every roof plane with its pitch. Covers most US homes.

3. Trace roof

Pick a tool, click the roof corners, double-click (or press Enter) to finish. Points snap to existing corners. Right-click or Backspace removes the last point. Esc cancels. In Select mode, drag corners to adjust and right-click a corner to delete it. Facets that touch are grouped into one structure; a detached shed or garage becomes Structure #2. Mark skylights or chimneys as Exclude on the facet to subtract them.

How it works

One-time setup: in DJI Fly, open Waypoints, drop any 2 points and save the route. This is the placeholder. The planner fills it with the real flight every time, so you always open that same route.

Send to DJI Fly (Android phone): turn on Developer options and USB debugging on the phone, plug it into this PC and tap Allow. The button reads the placeholder from the phone, fills it in, copies it back and closes DJI Fly so it reloads. The first time, it downloads Google's free adb tool (about 15 MB). Doesn't work with the DJI RC 2 or an iPhone.

Without USB: pick the placeholder file once (Android: Android/data/dji.go.v5/files/waypoint/<ID>/<ID>.kmz). After that, Download DJI Fly KMZ gives you a file with the same name to copy over the original. Or upload the Litchi CSV to Litchi Hub and export it to DJI Fly.

On site: take off from the ground next to the house, because every height is measured from the take-off point. Turn on obstacle avoidance and set the return-to-home altitude above the trees. Keep the drone in sight with your hands on the sticks. DJI doesn't support replacing the route file, and a DJI Fly update could break it.
